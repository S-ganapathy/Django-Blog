# 📝 Django Blog App

A fully functional blogging platform built using **Django**, based on the book **"Django 3 by Example"** by Antonio Mele.

This app allows users to browse blog posts, view details, comment, and share content — a great foundation for building a scalable blogging or content management system.

---

## 🌟 Features

- Blog post listing with pagination
- Individual post detail view
- Tag-based filtering
- Share posts via email
- Comment system
- SEO-friendly URLs using slugs
- Admin interface for managing posts, comments, and tags

---

## 🛠️ Built With

- **Python 3.8+**
- **Django 3.x**
- **SQLite3** (default for development)
- **Bootstrap 4** (for styling)
- **PostgreSQL** (optional, for production)
- **django-taggit** for tagging system
